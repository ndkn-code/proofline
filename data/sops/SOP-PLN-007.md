# Build a rolling forecast

## Purpose

Draft SOP for creating a 12 month rolling forecast version.

## Steps

1. Go to Planning > Forecasts > Create Version.
2. Choose the version type Rolling and a start period.
3. Copy actuals for closed months and enter forecast amounts for the rest.
4. Select Save.
