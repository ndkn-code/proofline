# Set up a recurring journal

## Purpose

Use this SOP to create a recurring journal template for entries that repeat every period.

## Steps

1. Go to General Ledger > Journals > Recurring Journals.
2. Select Create and enter a template name that starts with the prefix RJE.
3. Enter the journal lines and choose the frequency Monthly or Quarterly.
4. Enter an end date no later than 12 months after the start date.
5. Select Save, then Submit for Approval.

## Notes

- Recurring journals generate on business day 1 of each period.
- Review each generated journal before it posts.
