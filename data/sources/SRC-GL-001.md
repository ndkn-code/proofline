# Procedure capture: Create a manual journal entry

## Purpose

Use this SOP to record a one-time manual journal entry in the general ledger.

## Before you start

- You need the GL Journal Preparer role.
- Confirm the accounting period is Open before you start.

## Steps

1. Go to General Ledger > Journals > Create Journal.
2. Select the ledger HALDEN-US and enter a journal name that starts with the prefix MJE.
3. Choose the journal category Manual and an accounting date inside the open period.
4. Enter each line with a full account combination, a debit or credit amount and a line description.
5. Confirm total debits equal total credits, then select Validate.
6. Select Submit for Approval. Journals over $25,000.00 route to the GL Accounting Lead.

## Notes

- Attach support for any journal line over $5,000.00 before you submit.
- A journal that is saved but not submitted stays in Draft and does not post.
