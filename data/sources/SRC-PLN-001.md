# Procedure capture: Load a budget scenario from a template

## Purpose

Use this job aid to load budget amounts into a planning scenario from the standard spreadsheet template.

## Steps

1. Go to Planning > Budgets > Data Load.
2. Download the template for the scenario Budget FY27.
3. Enter amounts by department and account. Do not change the column headers.
4. Upload the completed file and select Validate.
5. Review the load log. Rows with errors are rejected and listed by row number.

## Notes

- The template accepts at most 5,000 rows per file.
