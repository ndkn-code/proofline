# Procedure capture: Submit a missing receipt declaration

## Purpose

Use this SOP when you lost a receipt for a business expense.

## Steps

1. Open the expense report from Expenses > Reports > My Reports.
2. Select the expense item that has no receipt.
3. Select Missing Receipt Declaration and enter the reason the receipt is unavailable.
4. Select Submit. Missing receipt declarations are limited to 3 per calendar year.
