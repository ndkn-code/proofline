# Procedure capture: Map a planning dimension to a GL segment

## Purpose

Use this SOP to map planning department members to the cost center segment of the chart of accounts.

## Steps

1. Go to Planning > Setup > Dimension Mapping.
2. Select the planning dimension and the GL segment it maps to.
3. Enter the mapping for each member and select Save.
4. Select Refresh Mappings so the next actuals load uses the new map.
