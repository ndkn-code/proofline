# Return goods to a supplier

## Purpose

Use this job aid to return received goods to the supplier.

## Steps

1. Go to Purchasing > Receipts > Return Items and open the receipt.
2. Select Return and enter the return quantity and the return reason.
3. Request a return authorization number from the supplier and enter it in the RMA Number field.
4. Select Submit. Returns must be entered within 45 calendar days of receipt.
