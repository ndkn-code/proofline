# Change an approved purchase order

## Purpose

Use this job aid to create a change order for a purchase order that is already approved.

## Steps

1. Go to Purchasing > Purchase Orders > Manage Orders and open the order.
2. Select Actions > Edit to create a change order.
3. Update the quantity, price or need-by date and enter a change description.
4. Select Submit. Changes that raise the order total by more than 10% route for reapproval.

## Notes

- You cannot change lines that are already fully received or invoiced.
