# Run the trial balance report

## Purpose

Use this job aid to run and export a trial balance for a ledger and period.

## Steps

1. Go to General Ledger > Reports > Trial Balance.
2. Select the ledger HALDEN-US, the period and the currency USD.
3. Set Account Level to Natural Account to see balances by account.
4. Select Run. The report opens in a new tab when it completes.
5. Select Export to download the report as a spreadsheet.

## Notes

- Trial balance figures include posted journals only.
- Large ledgers can take up to 10 minutes to run.
